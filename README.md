# Java DSA Practice & LeetCode Solutions

Daily data structures & algorithms practice in Java, ahead of placement season. Two parts, merged into one repo since they're the same effort:

## `leetcode-solutions/`

Solved LeetCode problems — one file per problem (arrays, linked lists, strings, searching).

## `dsa-practice/`

Topic-by-topic fundamentals practice, organized by concept:

| Folder | Topic |
|---|---|
| `ARRAY`, `ARRAYLIST`, `_2DARRAY` | Arrays, 2D arrays, ArrayList |
| `LINKED_LIST` | Linked lists |
| `STACK` | Stacks |
| `STRING` | String manipulation |
| `RECURSION`, `BACKTRACKING`, `DIVIDE_CONQUEROR` | Recursion and its variants |
| `SORTING` | Sorting algorithms |
| `BITWISE_MANIPULATION` | Bit manipulation |
| `LOOPING`, `NESTED_LOOP` | Loop fundamentals |
| `FUNCTION`, `VARIABLES`, `OOPS` | Core Java fundamentals |

Part of ongoing interview/placement prep — this repo grows as I work through new problems and topics.
